# Getting help

## Documentation

Start with the [README](README.md), then [COMPATIBILITY.md](docs/COMPATIBILITY.md) for
what's supported and [ON_DISK_FORMAT.md](docs/ON_DISK_FORMAT.md) for how a drive is
stored.

## Questions

Ask in [GitHub Discussions ▸ Q&A](https://github.com/teispace/teifs/discussions/categories/q-a).
Search first: someone may have asked already. Say which version and operating system you
use, which S3 client, what you tried and what happened.

## Bugs and feature requests

- A bug: open a [bug report](https://github.com/teispace/teifs/issues/new?template=bug_report.yml).
  An S3 client that misbehaves against TeiFS is a bug worth reporting: include the client,
  its version and the exact command.
- An idea: start a discussion in [Ideas](https://github.com/teispace/teifs/discussions/categories/ideas).

## Security issues

Never in public. See [SECURITY.md](SECURITY.md).
